Project Name
⇾ FitLog

Short Description
⇾ A dark-themed, interactive workout library web application that lets users browse exercises, view detailed instructions, and build personalized daily training plans.

Technologies Used
⇾ Next.js (App Router), React, Tailwind CSS v4, DaisyUI, Lucide React, and React Toastify.

5 Key Features
⇾ Dynamic Data Fetching: Automatically loads workout data, images, and stats from an external REST API.
⇾ Detailed Exercise Views: Provides step-by-step instructions, targeted muscle groups, and difficulty ratings for each lift.
⇾ Custom Workout Plans: Allows users to add and remove specific exercises to a "Today's Plan" tracker.
⇾ Save for Later (Bookmarking): Lets users save interesting workouts to a separate, dedicated list for future reference.
⇾ Real-time Stat Tracking: Automatically calculates and updates the total workout duration and calories burned based on the user's active plan.
